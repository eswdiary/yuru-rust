pub fn decode_cp1252_lossy(buf: &[u8]) -> impl Iterator<Item = char> + '_
Expand description

Create an iterator over Windows-1252 encoded characters in buf.

Invalid characters are substituted with the Unicode U+FFFD REPLACEMENT CHARACTER (�).

Windows-1252 is a strict superset of ISO/IEC 8859-1. In addition to the characters defined in ISO/IEC 8859-1, it contains all C0 control characters from ISO-8859-1, but uses the space reserved for the C1 control characters for additional printable characters.

Note: Some character codes residing in the C1 control character space are officially undefined in Windows-1252, but are mapped to C1 control characters when using Windows multi-byte conversion APIs. These character codes are considered invalid.
